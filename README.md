What was this project:I wanted to figure out what daily habits actually trigger my migraines, and whether I could build a tool to warn me if my daily numbers were heading into a high-risk zone. Instead of using pre-built libraries like scikit-learn, I wanted to code the machine learning math from scratch in Python to really understand how the decision-making and anomaly detection worked under the hood.How did I build this Project:I split the project into two main machine learning tools:The Migraine Trigger Ensemble: First, I tracked my daily habits (workout intensity, processed food, water intake, sun exposure, sleep hours, and screen time). To figure out which factors mattered most, I wrote my own decision tree algorithm from scratch using NumPy. I coded Shannon Entropy and Information Gain to decide where to split the data at each node. To keep the model from overfitting and to make it generalize better, I turned it into a 10-tree ensemble by implementing bootstrap sampling (sampling with replacement) and limiting each tree to a max depth of 3.The Safe-Zone Anomaly Detector: Next, I wanted to know if a specific day's routines were uncharacteristically off. I collected data on ambient temperature, water intake, and sun exposure, and wrote a Gaussian anomaly detection script. I calculated the mean ($\mu$) and variance ($\sigma^2$) for each feature using only my "normal" non-migraine days. Then, I wrote a vectorized probability density function that calculates how typical a day's stats look. Using a separate cross-validation dataset, I wrote a loop that tested 1,000 different threshold values ($\epsilon$) to find the exact probability cutoff that maximized the F1-score (balancing precision and recall). If a new day's probability falls below that threshold, the script flags it as a high-risk anomaly.Challenges:Continuous feature splits: Since most of my tracking metrics weren't simple yes/no numbers, finding where to split the decision tree was tricky. I had to sort all unique values for a feature, calculate midpoints between consecutive numbers, and evaluate Information Gain across every candidate threshold for every single feature.Gaussian assumption checks: Anomaly detection assumes features follow roughly a normal bell curve. I used Matplotlib to plot histograms for each column of tracking data to visually confirm they weren't heavily skewed before fitting the model.Vectorizing math without libraries: Initially, computing joint probabilities required nested loops over every day and every feature. Replacing those loops with NumPy matrix operations (broadcasting the matrix subtractions and taking row products) made the probability calculations run significantly faster.Handling zero division in metric tuning: While sweeping 1,000 threshold values for $\epsilon$, some extreme cutoffs predicted zero positive cases, causing divide-by-zero errors in precision and recall. I added quick conditional checks so the F1 score would handle edge cases without crashing the loop.What I am going to Improve:Right now, the decision tree ensemble and the anomaly detector run in two separate files. My next goal is to combine both scripts into a single daily checker where I can input my day's numbers and immediately get both a migraine probability prediction and an anomaly warning. I'd also like to start tracking new daily features, like stress levels and caffeine intake, to see if they improve the model's accuracy.
